# Fonts (optional)

The dashboard uses the Autodesk Artifakt typeface when these files are here, and falls back to Arial otherwise. They are not included in the repository.

If you are allowed to use Artifakt, put these three files in this folder (names must match), then run `py src/render.py`:

- `ArtifaktLegend-Bold.ttf`
- `ArtifaktElement-Regular.ttf`
- `ArtifaktElement-SemiBold.ttf`
